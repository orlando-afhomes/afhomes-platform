# 00 · Vercel Prototype Demo

[Staging index](README.md) · Next: [Project and database trial](01-firebase-project-and-database-trial.md)

## Start when

The current prototype builds locally, the sample-data configuration is reviewed, and the owner authorizes a preview. This step can run while the local backend is being built.

## Tools and steps

1. Review the [prototype verification record](../../01-prototype/ui-states/16-state-verification.md) and run the current production build against browser-memory sample data. Use the current package scripts.
2. Use [Vercel](https://vercel.com/docs/deployments/overview) for the preview. The owner verifies the plan terms and repository connection, then publishes the approved build. Hobby is restricted to qualifying personal, non-commercial use. If the project is ineligible, hold deployment until the owner approves an eligible plan. [Vercel Fair Use](https://vercel.com/docs/limits/fair-use-guidelines#commercial-usage)
3. Keep the preview entirely on sample data. Check the settings and build output for production project IDs, server credentials, and real files before sharing the link with the approved audience.

## Verify

Open the preview as a tester. Walk through public entry and the approved Admin demo using test identities. Refresh and confirm the in-memory records reset. Record the preview revision, checks, and open findings. A passing prototype preview does not certify the hosted database or the full production build.
