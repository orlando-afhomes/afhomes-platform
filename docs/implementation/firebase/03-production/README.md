# 03 · Production

[Roadmap](../README.md) · Previous environment: [Staging](../02-staging/README.md)

Set up the separate company-owned production Firebase project and open AFHomes after staging and import sign-off. Use the hosting option verified in staging. All approved modules launch together.

## Work in order

| Step | Guide | Finish before advancing |
| --- | --- | --- |
| 01 | [Project and database](01-firebase-project-and-database.md) | Production database, reviewed schema, backups, and cost controls are ready. |
| 02 | [Staff access and credentials](02-staff-access-and-server-credentials.md) | Approved staff identities and server credentials are configured. |
| 03 | [Backend, API, and storage](03-backend-api-and-file-storage.md) | The owner has verified the release under restricted access for authorized readiness checks and imports. |
| 04 | [Approved imports and readiness](04-approved-imports-and-readiness.md) | Import totals, checks, and recovery plan are signed off. |
| 05 | [Deployment and launch](05-deployment-and-launch.md) | The owner has opened that same checked release to its intended users. |
| 06 | [Monitoring, backups, and recovery](06-monitoring-backups-and-recovery.md) | The people responsible for maintenance can perform the documented checks. |

Read the [staging sign-off](../02-staging/05-release-rehearsal-and-sign-off.md) first. The owner approves production provisioning, billing, import execution, and launch. Use separate production identities, secrets, projects, and data. Maintain the authorized boundaries for deferred services after launch.
